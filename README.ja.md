# DetailSearch Linker

[English README](README.md)

「あの話は、どのノートに書いたっけ？」というときに、いま読んでいる文章から関連するノートを探せる Obsidian プラグインです。

たとえば、研究メモにある「認知負荷」を手がかりに、別のノートの本文を検索できます。見つかった内容を確認してから、その箇所へ移動できるリンクを作れます。相手のノート名に「認知負荷」が含まれている必要はありません。

検索はボタンやコマンドを実行したときだけ行います。ノートの内容を外部サービスへ送信することはありません。

## 今回の改善

- **PC版Obsidianでは、コピーせずに検索できます。** 語句を選択して、サイドバーの **DSL: 選択語を検索** アイコンを押します。コマンドから実行しても同じ動作です。
- **モバイル版Obsidianでは、コピーした語句を検索します。** コピー後に選択が残っていても、そのまま **DSL: コピー語を検索** を実行できます。選択を自分で解除する必要はありません。
- **候補の表示を終えたら、元の閲覧モードに戻ります。** プラグインが候補を表示するためにモードを切り替えた場合に限ります。タブ移動で候補が消えるときも同様です。
- **日本語の不自然な候補を減らしました。** 自動で語句を選ぶときに、「〇〇の」「〇〇し」のような途中で切れた表現を候補にしにくくしています。すべての不自然な区切りを防げるわけではありません。
- **よく使う語を候補にしやすくなりました。** 手動で登録した語や、リンク作成を通じて学習した語を優先します。また、候補が多いときは、本文が強調表示で埋まりすぎないように表示する語を調整します。

操作の違いは、下の使用例で確認できます。

## はじめに覚える3つの操作

ここでは、他のノートに同じ語句が見つかり、いまのノートで光っている箇所を「候補」と呼びます。画面上では「強調」と表記されることもあります。`DSL` は DetailSearch Linker の略です。

1. **文章全体から候補を探す**：虫眼鏡のアイコン、または **DSL: 本文候補を検索** を実行します。
2. **自分で決めた語句だけを探す**：PC版Obsidianでは語句を選択して **DSL: 選択語を検索**、モバイル版Obsidianでは語句をコピーして **DSL: コピー語を検索** を実行します。
3. **候補を消す**：**DSL: 強調を消す** を実行します。本文候補が表示されているときは、虫眼鏡のアイコンをもう一度押しても消せます。

虫眼鏡のアイコンは、選択した語句だけを検索するボタンではありません。文字が選択されていても文章から候補を探し、コピーした内容は読み取りません。

検索と候補の表示だけでは、ノート本文にリンクは書き込まれません。リンクを入れるのは、プレビューで **リンクを作成** を押したときです。

## 使用例

### PC版Obsidianで、選んだ語句の関連ノートを探す

研究メモにある「認知負荷」だけを検索したい場合の手順です。

1. 編集できる状態のノートで「認知負荷」を選択します。コピーは不要です。
2. サイドバーで **DSL: 選択語を検索** と表示されるアイコンを押します。コマンドパレットから同じ名前のコマンドを実行しても構いません。
3. 他のノートの本文に一致があれば、選んだ箇所が光ります。
4. 光った箇所にマウスを合わせ、候補のノート名、見出し、本文の抜粋を確認します。
5. 関連する内容だと確認できたら、**リンクを作成** を押します。

この操作では、同じノートにあるほかの「認知負荷」までまとめて光ることはありません。選んだ1箇所が対象です。

### モバイル版Obsidianで、コピーした語句を検索する

1. いまのノートで「認知負荷」を選択し、コピーします。
2. 選択が残ったまま、**DSL: コピー語を検索** を実行します。
3. プラグインがコピー内容を読み取り、残っている選択を解除して検索します。
4. 光った箇所をタップし、本文の抜粋を確認してから **リンクを作成** を押します。

よく使う場合は、Obsidianのモバイルツールバーに **DSL: 本文候補を検索** と **DSL: コピー語を検索** を登録すると便利です。サイドバーのアイコンから実行する場合も、モバイル版Obsidianではコピー語の検索になります。

同じ語句が何度も出てくる場合は、コピー時の選択箇所を使います。すでに選択を解除している場合は、カーソルに最も近い一致箇所が対象です。コピーした語句は、現在のノート本文にも存在する必要があります。

同じノートで同じコピー語の検索を繰り返すと、1回目で候補を表示し、次の実行で消します。さらに実行すると、もう一度検索します。

### 閲覧中のノートから候補を探し、読み終わったら元に戻す

1. リーディングモードでノートを開き、**DSL: 本文候補を検索** を実行します。
2. 候補を表示するため、一時的に編集画面へ切り替わります。
3. 気になる候補を開き、関連するノートの抜粋を読みます。リンクを作らず、確認するだけでも構いません。
4. **DSL: 強調を消す** を実行すると、候補が消えてリーディングモードに戻ります。

**ノート切替で強調を消す** がオンの場合は、別のノートやタブへ移動して候補が消えるときも、元のノートをリーディングモードへ戻します。この設定は初期状態でオンです。

もともと編集画面を使っていた場合は、そのままです。また、検索後に自分で表示モードを切り替えた場合は、その操作を尊重します。

プレビューの **ノートを開く** から行き先を確認する操作は例外です。元のノートへ戻って候補の確認を続けられるように、候補を残します。

### 「漸進」のような、短い専門用語を候補にする

自動では拾われにくい語を繰り返し使う場合は、手動辞書に登録します。

1. DetailSearch Linkerの設定で **手動辞書語** に「漸進」を追加します。複数の語は1行に1語ずつ書きます。
2. 設定を閉じ、本文に「漸進」があるノートを開きます。
3. **DSL: 本文候補を検索** を実行します。以前の候補が残っている場合は、先に消してから実行します。
4. 検索対象のほかのノートにも一致があれば、「漸進」が候補になります。「漸進性」のような長い語の中にある場合も探します。

辞書への登録は、他のノートに一致がなくても光らせる機能ではありません。検索範囲や除外設定も引き続き適用されます。

**リンク作成から語を学習** をオンにすると、実際にリンクを作成した語を辞書に記録し、次回以降の候補に役立てます。検索しただけでは学習しません。記録された語は **学習済み辞書語** で編集・削除できます。

### 不自然な語句が候補に残ったとき

文章から自動で候補を探す際は、単語の区切りを確認して、末尾に「の」「を」「し」などが残る表現を減らします。単に最後の文字だけを見て一律に削る仕組みではありません。

手動辞書・学習済み辞書の語、見出しや強調した語、選択・コピーして指定した語には、この除外を適用しません。自分で指定した語まで勝手に短くしないためです。

不要な候補が残る場合は、その候補のプレビューで **この語を無視** を押します。その語の強調が消え、次回の自動検索からも外れます。ただし、選択・コピーして検索した場合は、無視する語に登録されていても検索します。

## プレビューとリンクの使い方

候補を開くと、行き先のノート名、近くの見出し、本文の抜粋が表示されます。

- **リンクを作成**：現在のノートの対象箇所をリンクに置き換えます。行き先に見出しがあれば、その見出しへのリンクになります。見出しがなければ、ノートへのリンクになります。
- **ノートを開く**：リンクを作らずに、行き先の内容を確認します。
- **この語を無視**：今後の自動検索から、その語を外します。
- **強調を消す**：表示中の候補をすべて消します。

リンクの形式は、Obsidianの **ウィキリンクを使用** 設定に従います。オンなら `[[ノート名#見出し|語句]]` 形式、オフならMarkdown形式を使います。行き先のノートへ目印を書き足すことはありません。

PC版Obsidianでは、プレビューをクリックすると開いたままにできます。閉じるにはEscapeキーを押すか、本文をクリックします。

### キーボードで操作したい場合

Obsidianのホットキー設定で、次のコマンドにキーを割り当てられます。初期状態では割り当てていません。

- **次の強調へ移動**
- **前の強調へ移動**
- **カーソル位置のリンク候補を開く**

候補の横に表示される件数を非表示にしていても使えます。通常の編集中は、TabとEnterを文字入力・改行に使えます。

何も選ばずに **DSL: 選択語を検索** を実行すると、語句の入力欄が開きます。ここでも、現在のノート本文にある語句を指定してください。

**DSL: 自動抽出して検索** は、表示中の候補や選択状態にかかわらず候補を検索し直すための補助コマンドです。普段は **DSL: 本文候補を検索** を使えば十分です。

## 設定の選び方

最初は初期設定で試し、困っていることに合わせて少しずつ変えてください。

### 探すノートを絞る

- **対象フォルダ**：行き先として探したいフォルダを1行に1つ指定します。空欄なら、除外フォルダ以外が対象です。
- **除外フォルダ**：テンプレートや自動生成ノートなど、探さなくてよいフォルダを指定します。
- **検索範囲**：古いノートも探すなら **対象フォルダ全体**、最近のメモに絞るなら **最近更新したノート** を選びます。**作業集合** は、最近開いたノートのことです。
- **最近更新（日数）**：最近更新したノートを探す期間です。初期値は30日です。`0` にすると日数で制限しません。
- **作業集合サイズ**：最近開いたノートを覚える件数です。`0` にすると件数で制限しません。
- **最大走査ファイル数**：1回で調べるノート数です。初期値は500件です。上限を超えたノートは、その回には検索しません。
- **最大ファイルサイズ**：初期値は512 KBです。これより大きいノートは検索しません。

対象フォルダは「リンク先をどこから探すか」の設定です。いま開いているノートから語句を取り出すかどうかを決めるものではありません。フォルダを絞っても、表示中のノートでは候補を探せます。

### 候補が多すぎる・少なすぎる

- **候補数の調整方法**：初期設定の自動調整では、本文が光りすぎないように表示する語を選びます。表示上限を自分で決めたい場合は固定上限へ切り替えます。
- **自動候補数の基準**：初期値は40件です。自動調整では候補を広めに検索してから表示する語を選ぶため、必ず40語になるわけではありません。
- **見出し・強調を優先抽出**：見出し、太字、`==ハイライト==` から候補を選びます。初期状態でオンです。
- **通常本文から語句抽出**：普通の文章からも候補を選びます。初期状態でオンです。見出しや強調した部分だけに絞りたいときはオフにします。
- **最小語長 / 最大語長**：自動で選ぶ語句の長さを調整します。短い専門用語を確実に検索したい場合は、手動辞書か選択・コピー検索を使ってください。
- **広域 n-gram 抽出**：文章を一定の文字数で細かく区切って探す追加機能です。不自然な断片も増えやすいため、まずは初期設定のオフで使うことをおすすめします。関連する最小長・最大長・上限の設定は、この機能をオンにした場合に使います。
- **停止語**：`the` や `and` のように、自動検索の候補から外す一般的な語です。
- **無視する語**：自分で候補から外した語です。プレビューの **この語を無視** で追加できます。

選択・コピーによる検索では、自動で候補を選ぶ設定や無視する語の一覧に関係なく、指定した語句を検索します。**大文字と小文字を区別** は検索の一致判定に使うため、これらの検索にも適用されます。

辞書や無視する語などを設定で変更したあとは、ノートに戻って検索し直してください。設定を変えただけでは、新しい候補は表示されません。

### 表示と保存について

- **光らせ方**：反転、マーカー、文字色、下線から選べます。
- **候補ノート数バッジ**：語句の横に、行き先のノート数を表示します。
- **抜粋の文字数**：プレビューに表示する本文の長さを変えます。
- **1ノートあたりの最大一致数 / 最大候補ノート数**：表示する検索結果の上限です。上限を超える一致は省略されます。
- **ノート切替で強調を消す**：オンなら、別のノートへ移ったときに候補を消します。オフなら元のノートに候補を残します。
- **キャッシュ**：同じ語を再検索するときに、以前の結果を使って待ち時間を減らします。**メモリのみ** ならObsidianを閉じたときに消えます。初期設定の **上限付き永続** では、次回起動後も使えるように保存します。
- **キャッシュ上限 (MB)**：保存量の上限です。超えた分は古い検索語から削除します。
- **UI 言語**：プラグインのボタンや設定の表示言語を変えます。

## うまくいかないとき

### 語句が光らない

順に確認してください。

1. **押したボタンは目的に合っていますか？** PC版Obsidianで選んだ語だけを探すなら **DSL: 選択語を検索** です。虫眼鏡は文章全体から候補を探します。
2. **コピーした語句は、現在のノートにもありますか？** コピー検索は、ノート外の文章を検索する入力欄ではありません。
3. **他のノートの本文にも同じ語句がありますか？** ファイル名にあるだけでは候補になりません。
4. **そのノートは検索対象に含まれていますか？** 対象・除外フォルダ、検索範囲、件数・サイズの上限を確認します。
5. **既存のリンクやコードの中を選んでいませんか？** これらの部分は対象外です。
6. **自動検索で拾われない語ですか？** 選択・コピー検索で試し、繰り返し使う語なら手動辞書に登録します。

候補が表示されている状態で虫眼鏡を押すと、検索ではなく候補の消去になります。もう一度押すと検索します。

### 「キャッシュから」と表示される

以前の検索結果を再利用したことを示す表示で、失敗の意味ではありません。結果に疑問がある場合は **検索キャッシュを消去** してから検索し直すと、切り分けに役立ちます。キャッシュを消してもノート本文は削除されません。

### コピー内容を取得できない

ノートの語句をもう一度コピーし、すぐに **DSL: コピー語を検索** を実行してください。端末から貼り付けの許可を求められた場合は、許可して再度試してください。

## 導入と更新

Obsidian **1.13.0以降** に対応しています。PC版Obsidianとモバイル版Obsidianで使えます。

### GitHubからインストールする

1. [GitHub Releases](https://github.com/zoupuyo-obsidian/obsidian-detailsearch-linker/releases) で使いたい版を開き、`main.js`、`manifest.json`、`styles.css` をダウンロードします。
2. 保管庫（Vault）の `.obsidian/plugins/detailsearch-linker/` に3つのファイルを置きます。フォルダがなければ作成します。
3. Obsidianの **設定 → コミュニティプラグイン** から有効にします。

更新時は3つのファイルを同じ版のものに置き換え、プラグインをオフ・オンするかObsidianを再起動してください。設定ファイルの `data.json` を削除する必要はありません。

コミュニティプラグインの一覧に掲載されている場合は、一覧からインストール・更新できます。

### BRATでテスト版を使っている場合

すでにBRATに登録している場合は、追加登録は不要です。BRATからこのプラグインを更新してください。特定の版を指定している場合は、その指定も確認します。

初めて登録する場合のリポジトリ名は `zoupuyo-obsidian/obsidian-detailsearch-linker` です。テスト版も正式版も同じプラグインとして扱うため、別の開発用プラグインを追加する必要はありません。

## ノートの保護とプライバシー

既存のリンク、コード、数式、ノート先頭のプロパティ欄は、検索・候補の取り出しの対象外です。これらに重なる範囲を選択した場合は、通知して処理を止めます。検索語に `|`、`[`、`]` は使えません。

プラグインはノートの内容を外部へ送信しません。保存するキャッシュは検索語、ファイルの場所、見出し、一致位置、更新日時です。本文全体やプレビューの抜粋は保存しません。

手動辞書と学習済み辞書も、この保管庫のプラグイン設定に保存します。学習済みの語は最大200語で、編集・削除・一括消去できます。**メモリのみ** に変える設定は検索キャッシュ用であり、辞書を消去するものではありません。

保管庫を同期・バックアップしている場合、プラグインの設定ファイルもその対象になることがあります。

## Spot Linkerとの違い

[Spot Linker](https://github.com/zoupuyo-obsidian/obsidian-spot-linker) は、別ノートの名前や別名に合う語句からリンクを作るためのプラグインです。DetailSearch Linkerは、別ノートの**本文**に書かれた語句を探します。

たとえば「認知負荷.md」へリンクしたいならSpot Linker、日付付きの研究メモにある「認知負荷」の説明へリンクしたいならDetailSearch Linkerが向いています。併用でき、無視する語の一覧もそれぞれ別です。

## 開発・ライセンス

開発手順は [CONTRIBUTING.md](CONTRIBUTING.md) を参照してください。

```bash
npm install
npm test
npm run build
npm run lint
```

開発版を差し替えたあとは、プラグインをオフ・オンするかObsidianを再読み込みしてください。`npm run verify:release` で版情報と配布ファイルを検証できます。
